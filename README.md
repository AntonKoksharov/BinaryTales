# CodePlot
Команда CodePlot.

Цель проекта «ФинСмарт»:

Помочь пользователям навести порядок в личных финансах, находить скрытую экономию и без стресса достигать денежных целей с помощью ИИ и геймификации.

Состав разработчиков:

1. Кокшаров Антон(@antonkoksharov1) - Backend-разработчик.
2. Зинкевич Анастасия(@nastyz_222) - Frontend-разработчик.

Планируемый стек технологий:

Backend:
Python (FastAPI) - асинхронный REST API и бизнес-логика
SQLite / PostgreSQL - хранение пользователей, категорий и транзакций
Pydantic - валидация данных запросов
Swagger / OpenAPI -- интерактивная документация API

Frontend:
HTML5 & CSS3 - семантическая структура и адаптивная верстка интерфейса
Vanilla JavaScript - клиентская логика и асинхронное взаимодействие с API 
Chart.js - визуализация графиков расходов и статистики
